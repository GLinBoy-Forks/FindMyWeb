# FindMyWeb config
## `jwt`
- `secret`: secret used for the encryption of the token
  - Generate using `openssl rand -hex 32`
- `expire`: token expiry time in `minutes`
- `secret_refresh`: secret used for the encryption of the refresh token
  - Generate using `openssl rand -hex 32`
- `expire_refresh`: refresh token expiry time in `hours`
- `algorithm`: algorithm used for the token
  - should be `HS256`

## `admin`
The password of the admin (superuser) user gets reset every restart
- `name`: the name of the admin
- `password`: plaintext password for the admin

## `findmy`
- `account`: path to the `account.json` file generated with `login.py`
  - see [login](login.md)
- `libs_path`: libs path used in `login.py`

## `db`
- `uri`: a uri to specify the database
  - can be any uri supported by [sqlalchemy](https://docs.sqlalchemy.org/en/20/core/engines.html)

## `frontend`
- `path`: path to the `dist` folder of the frontend generated by `deno`

## `log`
Configuration for python's logging library. For more info see [python.org](https://docs.python.org/3/library/logging.config.html#logging-config-dictschema) and [pydantic-settings-logging](https://github.com/vduseev/pydantic-settings-logging/tree/v0.1.1?tab=readme-ov-file#toml-configuration-loggingtoml)
